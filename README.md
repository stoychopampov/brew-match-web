# Brew Match — web preview

Test preview of **Brew Match by Rhombus**, a match-3 puzzle game by Rhombus
Craft Brewery (Pazardzhik, Bulgaria). For adults (18+).

Play: https://stoychopampov.github.io/brew-match-web/

This repository holds only the compiled web build (generated with
`flutter build web --release --base-href /brew-match-web/`). The game's
source lives in a private repository.

Visits are counted with [GoatCounter](https://www.goatcounter.com): no
cookies, no personal data, just anonymous page-load counts. The Android and
iOS apps contain no analytics.
